### 1. Описание функциональности монолитного приложения

**Управление отоплением:**

- Пользователи могут удалённо включать/выключать отопление в своих домах, задавать целевую температур в доме.
- Система поддерживает синхронные методы для включения отопления, выключения отопления, задания целевой температуры.

**Мониторинг температуры:**

- Пользователи могут просматривать текущую температуру в своих домах через веб-интерфейс.
- Система поддерживает синхронный метод для получения текущей температуры в доме.

### **4. Проблемы монолитного решения**

- При изменении одной части приложения высок риск внести ошибки, которые будут непредсказуемо влиять на поведение системы.
- Так как при внесении изменений в приложение приходится тестировать все приложение целиком, то длительность циклов разработки и развертывания становится большой.
- Масштабировать приложение можно только целиком, что приводит к нерациональному использованию вычислительных ресурсов в случаях, когда разворачивать новый инстанс приходится лишь для уменьшения нагрузки на один компонент системы.
- Из-за использования единой кодовой базы при изменении одного компоненты велика вероятность повлиять на другие компоненты, что приводит к конфликтам в команде.
- Использование единого стека технологий часто может оказаться нерациональным, т.к. определенные задачи на другом стеке могут решаться эффективнее.
